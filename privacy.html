Конфиденциальность

Ваши данные остаются под вашим контролем.

WebDevGym использует только те данные, которые нужны для входа, синхронизации учебного прогресса и работы выбранных функций.

Какие данные обрабатываются

  • при входе через Google или GitHub: идентификатор аккаунта, имя, адрес электронной почты и аватар, если провайдер их передаёт;
  • учебный прогресс, настройки и данные профиля, которые вы сохраняете в WebDevGym;
  • данные, созданные локальными инструментами, могут оставаться только в браузере на вашем устройстве.

Для чего используются данные

Для авторизации, восстановления вашей сессии, синхронизации прогресса между устройствами и отображения вашего профиля. WebDevGym не продаёт персональные данные и не использует их для рекламного профилирования.

Хранение и сторонние сервисы

Авторизация и облачное хранение работают через Supabase. Вход через Google и GitHub регулируется политиками этих сервисов. Сайт размещён на Vercel. Каждый сервис обрабатывает данные в пределах своей роли.

Удаление данных

Вы можете выйти из аккаунта и продолжить работать локально. Чтобы запросить удаление облачного аккаунта и связанных данных, создайте обращение в репозитории WebDevGym.

Обновления политики

При изменении способов обработки данных эта страница будет обновлена. Последнее обновление: 28 октября 2026 года.
